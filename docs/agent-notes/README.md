# GroceryHub — Cross-Agent Change Requests (`CR-nnn`)

Per `AGENTS.md` §3 and `docs/spec/09-AGENT-ORCHESTRATION.md` §3, each file path has a single owner. No agent may edit a file it does not own. When an agent needs a change in another owner's path, it creates `docs/agent-notes/CR-<nnn>-<slug>.md` and registers it in the index below.

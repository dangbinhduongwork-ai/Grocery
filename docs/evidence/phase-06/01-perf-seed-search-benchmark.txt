================================================================================
  Index Justification & Search Strategy Summary                                
================================================================================
1. Vietnamese Normalization Strategy:
   - SearchText column stores pre-computed, lowercased, diacritic-free tokens
   - Normalizes 'Đ/đ' -> 'd', removes Vietnamese tone marks, decomposes and filters NonSpacingMark
   - Eliminates collation mismatch and allows lightning-fast substring / prefix scans without expensive runtime functions
2. Filtered Covering Index:
   - IX_Products_SearchText: (SearchText) INCLUDE (Id, Name, Slug, CategoryId, BrandId, SellingPrice, ListPrice, Status, SoldCount)
   - Filter: WHERE Status = 'Active' AND DeletedAt IS NULL
   - Ensures query resolves directly from index pages without key lookups on the base clustered table
3. Benchmark Results:
   - p95 latency for queries ('sua tuoi', 'rau cu', 'nuoc mam') across 20,000 products: well below 300 ms target.

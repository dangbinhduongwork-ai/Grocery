# GroceryHub — QA Test Plan & Requirement Traceability (`docs/qa/test-plan.md`)

## 1. Phase 04 Test Strategy Overview

GroceryHub enforces a strict, zero-fake verification strategy (`docs/spec/12-TESTING-STRATEGY.md`, `.agents/rules/testing.md`):

1. **Unit Tests (`tests/GroceryHub.UnitTests`):**
   - Exercise pure `GroceryHub.SharedKernel` domain primitives, business rules, and Vietnamese conventions in isolation with deterministic `FakeTimeProvider` (`Microsoft.Extensions.TimeProvider.Testing`).
   - Verify exact integer VND arithmetic (`Money`), moving-average cost calculation (`BR-01`), discount/allocation remainder conservation, `Result` / `Result<T>` / `DomainError` error taxonomy (`ADR-006`), `Guard` clauses, `PageRequest` / `PagedList<T>` clamping, `VietnamesePhone` normalization (`BR-17`), `VietnameseTextNormalizer` accent-stripping and slug generation, and `VietnamTime` (`Asia/Ho_Chi_Minh`, `UTC+07:00`) day boundary and `yyMMdd` order prefix calculation (`ADR-007`).

2. **Architecture Tests (`tests/GroceryHub.ArchitectureTests`):**
   - Enforce structural invariants from `docs/spec/05-SYSTEM-ARCHITECTURE.md` §10 / §15 on every build:
     1. Module isolation (`GroceryHub.Modules.*` depend only on `GroceryHub.SharedKernel` and `*.Contracts`; verified at namespace level with `NetArchTest.Rules`, assembly reference level, and `.csproj` `<ProjectReference>` XML level).
     2. API layer purity (`GroceryHub.Api` types never depend on `GroceryHub.Persistence.Entities` or inherit `Entity<>` / `AggregateRoot<>`).
     3. Default-deny endpoint security (every mapped `RouteEndpoint` resolved from `WebApplicationFactory<Program>` declares either `IAuthorizeData` or `IAllowAnonymous`).
     4. Deterministic time & async discipline (zero IL or source calls to `DateTime.Now`, `DateTime.UtcNow`, `DateTimeOffset.Now`, `DateTimeOffset.UtcNow`, or `Thread.Sleep` across all `src/` projects).
     5. Commercial license guardrail (`DEC-003` / `ADR-004` — zero assembly or package references to `MediatR`, `AutoMapper`, `FluentAssertions`, `MassTransit`, or `Duende`).
   - **Mutation Sanity Proof:** Verified in [`docs/evidence/phase-04/03-arch-test-mutation-proof.txt`](../evidence/phase-04/03-arch-test-mutation-proof.txt) by injecting a forbidden project reference and type reference from `GroceryHub.Modules.Ordering` to `GroceryHub.Modules.Catalog`, confirming `dotnet test tests/GroceryHub.ArchitectureTests` fails with exit code `1`, reverting the mutation, and confirming `dotnet test` passes with exit code `0`.

3. **Integration Tests (`tests/GroceryHub.IntegrationTests`):**
   - Use `WebApplicationFactory<Program>` (`GroceryHubWebApplicationFactory`) backed by a real SQL Server database managed by `SqlServerTestDatabaseFixture` (`IAsyncLifetime`).
   - `SqlServerTestDatabaseFixture` starts `Testcontainers.MsSql` (`MsSqlBuilder`) when a Docker daemon is reachable, or automatically provisions an isolated real SQL Server database (`GroceryHub_IntTests_<Guid:N>`) on `(localdb)\MSSQLLocalDB` when Docker is unavailable on Windows, runs `dbContext.Database.MigrateAsync()` applying the real `20261115044356_Baseline` migration, resets tables between tests via `Respawn` 6.2.1 (`DbAdapter.SqlServer`, all 12 module schemas included, `shared.__EFMigrationsHistory` ignored), and drops the test database on `DisposeAsync()`.
   - Zero skipped tests (`Skipped: 0`), zero `Thread.Sleep` / `Task.Delay` synchronization, and zero mocked units under test.
